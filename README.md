# Digital Business Card

A simple and elegant digital business card built using HTML and CSS. This project showcases personal information in a clean card-based layout, including a profile image, name, profession, and location.

## Preview

The business card features:

- Professional profile photograph
- Name display
- Role/Profession information
- Country information
- Clean and modern user interface
- Responsive card layout

## Technologies Used

- HTML5
- CSS3

## Features

- Minimalist design
- Easy to customize
- Lightweight and fast
- Beginner-friendly project
- Modern card-style layout

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/business-card.git
```

2. Open the project folder.

3. Launch `index.html` in your web browser.
